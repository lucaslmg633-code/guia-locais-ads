# Guia de Locais — CP3 (ADS)

Site desenvolvido como entrega acadêmica (**CP3**) na graduação em **Análise e Desenvolvimento de Sistemas**, estruturado como um guia visual de locais e espaços (incluindo página dedicada ao *Parque Centenário* e ilustrações vetoriais em `SVG`).

🔗 **Site publicado:** [lucaslmg633-code.github.io/cp3-entrega](https://lucaslmg633-code.github.io/cp3-entrega/)

---

## 🛠️ Tecnologias Utilizadas
* **HTML5** (54.5%) — Estruturação das páginas (`index.html`, `parque-centenario.html`)
* **CSS3** (43.5%) — Estilização e layout (`style.css`)
* **SVG** — Ilustrações e ícones vetoriais dos locais
* **GitHub Pages** — Publicação web
